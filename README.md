## espectro

Um registo da imprensa portuguesa, em [oespectro.eu](https://oespectro.eu): quem é dono de cada órgão de informação, com as fontes, e quem publica o quê, medido todos os meses.

Os dados saem em ficheiros mensais, CC BY 4.0, em [dados](https://github.com/espectro-dados/dados). Contacto em contacto@oespectro.eu.
